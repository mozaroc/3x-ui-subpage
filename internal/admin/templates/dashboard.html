Admin dashboard

Manage every admin-editable part of the subscription service:

  • Settings — server/xui/subscription/security/logging/support/qr
  • Applications — the catalog shown on the subscription page
  • Themes — HTML/CSS/JS + metadata for the subscription page
  • Templates — Xray/Clash/Mihomo/Happ/Incy config templates, per profile
  • Assignments — which subscribers use which template profile
  • Routing — GEOIP/geosite/domain/CIDR/process/DNS/custom rules, per profile
  • Users — create/edit/suspend/reset-traffic/assign-inbounds; synced to 3x-ui automatically
  • Sync — recent synchronization jobs and their status, with manual retry
{{end}}

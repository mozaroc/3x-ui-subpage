Routing (Happ / Incy)

Configures the client apps' own native Routing Profile (per Happ's Routing Generator) -- unrelated to the Xray/Clash/Mihomo config formats above. When enabled, the generated profile is embedded into this user's Happ and Incy deep links automatically (via the Routing/Routing-Enable response headers); when disabled, those clients get no routing configuration at all.
